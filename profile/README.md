Noir Stack builds software that helps teams understand complex systems and act on evidence. Our products connect data, investigations, workflows, AI, and infrastructure so the context behind a decision can travel with the work.

## One connected environment

Use a single product or connect several into a broader operating environment.

| Product | Purpose |
| --- | --- |
| [Hexarch](https://hexarch.systems/) | Structure incoming signals and produce verifiable execution artifacts. |
| [Judicium](https://judicium.app/) | Connect entities and evidence to support investigations. |
| [Cascades](https://cascades.work/) | Coordinate workflows and carry decisions into execution. |
| [AITracer](https://aitracer.app/) | Inspect AI activity, apply controls, and follow decision history. |
| [NOIR AI](https://noirai.app/) | Develop and deploy AI-powered systems. |
| [LedgerBill](https://ledgerbill.app/) | Link usage and pricing to auditable billing. |
| [WordMaker](https://wordmaker.cc/) | Develop written work and preserve reusable knowledge. |
| [CodeCraft](https://codecraft.icu/) | Build interfaces and iterate on working applications. |
| [Schemarch](https://schemarch.com/) | Manage schemas, access, environments, and infrastructure controls. |

## How we build

- **Keep the evidence.** Preserve sources, relationships, and decision history.
- **Make actions inspectable.** Design for traceability, observability, and reproducibility.
- **Connect the work.** Carry shared context across product boundaries.
